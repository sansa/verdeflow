# Agent guidance

When asked to start tracked work, create or find a GitHub issue, or create a branch, use [github-start-work](.agents/skills/github-start-work/SKILL.md). The shared human-readable rules are in [GitHub work-start convention](doc/contributing/GITHUB_WORKFLOW.md). Ordinary file edits do not require an issue or branch unless the contributor asks for that workflow.

The documents under `doc/prototype/` describe the earlier VerdeFlow codebase. Treat them as historical references, not instructions for this repository.
