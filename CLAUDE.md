# Claude Code guidance

For requests to start tracked work, create or find a GitHub issue, or create a branch, use the project skill at [.claude/skills/github-start-work/SKILL.md](.claude/skills/github-start-work/SKILL.md). Its shared rules are in [doc/contributing/GITHUB_WORKFLOW.md](doc/contributing/GITHUB_WORKFLOW.md). Ordinary edits do not require an issue or branch unless requested.
