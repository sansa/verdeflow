# Start tracked VerdeFlow work

Read and follow the shared [GitHub work-start convention](../../../doc/contributing/GITHUB_WORKFLOW.md). Search for an existing issue first, use labels that exist in the repository, and branch only for repository file changes. Report the issue URL, labels, branch or reason for no branch, risk, and next step. Ordinary edits do not trigger this workflow.
